# 17 — REST API

## Описание

Простой REST API сервис на Flask с проверкой аутентификации через API-ключ в заголовках запроса.

## Концепции

* Flask, jsonify(), request.headers
* API Key Authentication (`X-API-Key`)
* HTTP Status Codes (`200 OK`, `401 Unauthorized`)

## Как запустить

python REST_API.py
