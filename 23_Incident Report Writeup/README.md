23 — Incident Report Writeup
Описание

Python скрипт который генерирует профессиональный отчёт об инциденте безопасности в формате Markdown. Симулирует работу SOC-аналитика после реальной атаки.

Концепции
Incident Response (IR)
IOC (Indicators of Compromise)
Timeline документирование
Remediation планирование
Технологии
Python
Markdown
Как запустить
python incident_report.py
Результат

Генерирует файл report.md со структурой:

Summary — краткое описание инцидента
Timeline — хронология событий
IOC — технические улики
Remediation — действия по устранению
