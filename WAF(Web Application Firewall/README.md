🛡️ №21 — WAF (Web Application Firewall)
Описание
Простой Web Application Firewall на Python + Flask.
Перехватывает входящие запросы и блокирует их если они содержат подозрительные паттерны — XSS, SQL Injection, Path Traversal.

Как это используется в реальной кибербезопасности
WAF стоит между пользователем и веб-сервером. Каждый запрос проходит через него.
Если запрос содержит атаку — WAF блокирует его до того как он дойдёт до сервера.
Реальные аналоги: Cloudflare WAF, AWS WAF, ModSecurity.

Реальный случай: В 2019 году Capital One потерял данные 100 миллионов клиентов из-за неправильно настроенного WAF.

Что умеет скрипт
Запускает локальный веб-сервер на Flask
Принимает входящие запросы с параметром input
Проверяет запрос на наличие опасных паттернов
Возвращает BLOCKED если атака обнаружена, OK если запрос безопасен
Заблокированные паттерны
Паттерн	Тип атаки
<script>	XSS (Cross-Site Scripting)
SELECT	SQL Injection
DROP TABLE	SQL Injection
../	Path Traversal
Пример использования
Запусти скрипт, затем открой браузер:

# Безопасный запрос
http://127.0.0.1:5000/?input=hello
→ OK

# XSS атака
http://127.0.0.1:5000/?input=<script>alert(1)</script>
→ BLOCKED
