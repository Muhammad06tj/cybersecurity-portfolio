# 25 — SOC Simulation
 
## Описание
Python скрипт который симулирует работу SOC-аналитика. Читает лог-файл с событиями безопасности и автоматически обнаруживает подозрительную активность.
 
## Как работает
- Читает `security.log` построчно
- Парсит каждое событие по разделителю `|`
- Обнаруживает три типа угроз и выводит алерты
## Триггеры алертов
- `FAILED_LOGIN` — неудачная попытка входа
- `FILE_CREATED` — создан подозрительный файл в системе
- Ночная активность — любое событие между 00:00 и 06:00
## Концепции
- Log Analysis
- Alert Triage
- IOC Detection
- SOC Workflow
## Технологии
- Python
## Как запустить
```
python soc_simulation.py
```
 
## Пример вывода
```
[ALERT] Неудачная попытка входа: FAILED_LOGIN ip=192.168.1.168 user=jon
[ALERT] Ночная активность в 3 часа ночи: SUCCESS_LOGIN user=jon
[ALERT] Создан подозрительный файл
[ALERT] Ночная активность в 5 часа ночи: FILE_CREATED user=jon
```
