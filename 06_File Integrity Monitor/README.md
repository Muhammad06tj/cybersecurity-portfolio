# 06 — File Integrity Monitor

## Описание
Мониторинг целостности файлов — обнаруживает изменения через сравнение хешей. Основа SIEM-систем.

## Концепции
- Чтение файлов в байтовом режиме rb
- hashlib.sha256(f.read()).hexdigest()
- Сравнение хешей

## Как запустить
python file_integrity_monitor.py
