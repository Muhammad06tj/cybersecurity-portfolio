22 — Brute-Force Protection
Описание
Система защиты Flask-приложения от атак перебора паролей. Отслеживает неудачные попытки входа по комбинации IP + username и блокирует доступ после превышения лимита.

Как работает
Считает неудачные попытки для каждой пары IP + имя пользователя
Блокирует после 5 неудачных попыток
Автоматически сбрасывает блокировку через 15 минут
Концепции
Rate limiting
Account lockout
Time-based lockout
Словарь как хранилище состояния между запросами
Технологии
Python
Flask
Модуль time
Как запустить
python brute_force_protection.py
Тестирование
curl -X POST http://127.0.0.1:5000/login -d "username=test&password=wrong"
