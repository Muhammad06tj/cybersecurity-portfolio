# 30 — AI Phishing Detection
 
## Описание
Python скрипт который использует языковую модель через API для анализа текста письма и определения является ли оно фишинговым. Пользователь вводит текст письма и получает детальный анализ с объяснением признаков фишинга.
 
## Как работает
- Принимает текст письма через input()
- Отправляет POST запрос к Groq API с языковой моделью
- Получает анализ и вердикт от модели
- Выводит результат в читаемом формате
## Концепции
- NLP (Natural Language Processing)
- AI/LLM API интеграция
- Phishing Detection
- REST API запросы с авторизацией
## Технологии
- Python
- Groq API
- requests
- Модель: qwen/qwen3.8-27b
## Как запустить
```
python ai_phishing_detection.py
```
 
## Пример использования
```
Введите текст письма: Ты выиграл приз открой ссылку
 
Это письмо содержит все классические признаки фишинга.
Вывод однозначный: ДА, это фишинговое письмо.
```
