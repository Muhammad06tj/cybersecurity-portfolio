# 19 — Phishing Analyzer

## Описание

Скрипт для базового анализа электронных писем на фишинг путем поиска ключевых слов-маркеров и внешних HTTP-ссылок.

## Концепции

* Регулярные выражения (`re.findall`)
* Оценка уровня угрозы (Scoring System)
* Выявление фишинговых паттернов и незащищенных ссылок (`http://`)

## Как запустить

python Phishing_analyzer.py
